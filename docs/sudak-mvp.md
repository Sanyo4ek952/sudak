# Sudak Stay — MVP+ (PRD → IA/UX → UI → Tech → Реализация)

## 1) Допущения (Assumptions)
- MVP без реальных платежей: сохраняем статусы «предоплата/оплата», платежный провайдер — мок.
- Вся модерация и правила отмены — внутри админ-панели, юридические документы пока в виде простых страниц.
- 3D-герой включается только при наличии WebGL и достаточной мощности; по умолчанию — статичный арт.
- Email-уведомления — мок/лог, готовность интеграции через Resend/SMTP.
- Демо-данные Судака включены через seed Prisma.

## 2) PRD
### Цели продукта
- Быстрое и доверительное бронирование жилья в Судаке.
- Прозрачная all-in цена на каждом шаге.
- Минималистичная, «дорогая» эстетика + высокая скорость.
- Лид-магнит для органического роста и повторных визитов.

### Метрики
- CR поиска → карточка: 45%+
- CR карточка → бронирование: 12%+
- CR бронирование → подтверждение: 6%+
- CR лид-магнита: 15%+
- Повторные визиты: 25%+

### Core user stories
- Guest: хочу увидеть итоговую цену до ввода данных и быстро забронировать.
- Host: хочу массово менять цены и доступность без сложных таблиц.
- Admin: хочу быстро модерировать карточки и спорные бронирования.
- Guest: хочу получить маршрут по Судаку и сохранить его.

### Scope
**MVP:** поиск, карточка, бронирование (до 4 шагов), личный кабинет гостя, кабинет хоста с календарем, чат, лид-магнит, калькулятор.
**V1:** real payment, отзывы с фото, интеграция с внешним календарем, персональные рекомендации.

## 4) UX
### Ключевые экраны
- Главная
- Поиск
- Карточка объекта
- Бронирование
- ЛК гостя
- ЛК хоста
- Админ-панель
- Лид-магнит «Судакский квест»
- Калькулятор бюджета

### Wireframe-описания + microcopy
- Главная: крупный заголовок, короткий подзаголовок, CTA «Найти жильё», блок доверия, 3D-герой.
  - Microcopy: «Итоговая цена видна сразу», «Без скрытых комиссий».
- Поиск: верхний фильтр + карточки в списке; слева — фильтры; в карточке — цена/ночь и район.
  - Microcopy: «Сортировка: цена / рейтинг / близость к морю».
- Карточка: галерея, удобства, правила, отзывы, карта района, блок бронирования.
  - Microcopy: «Итоговая цена», «Бесплатная отмена за 7 дней».
- Бронирование: 3 шага — даты/гости → данные → подтверждение.
  - Microcopy: «Вы можете продолжить как гость, но аккаунт сохранит маршрут и скидки».
- ЛК гостя: блоки «Мои брони», «Сообщения», «Избранное».
- ЛК хоста: список объектов, календарь и правила цен.
- Лид-магнит: 5–7 вопросов, результат + «Скопировать результат».
- Калькулятор: ввод дат, гостей, опций; на выходе — диапазон бюджета.

## 8) Definition of Done
### Чек-лист приемки
- Прозрачная итоговая цена видна в карточке и бронировании.
- Мобильная версия читаема, фокус и контраст соблюдены.
- 3D-герой с fallback.
- Календарь хоста позволяет менять цены/доступность.
- Лид-магнит и калькулятор имеют «Скопировать».

### Edge cases
- Овербукинг при одновременных бронированиях.
- Изменение цены после создания брони.
- Таймзоны и смена дня.
- Отмена в день заезда.
- Валидация гостей/дат.
